# ADR-002：同一份 Skill 双发现（项目级 + 插件级）

- 状态：已接受（2026-08-13）
- 决策：plugin root = 仓库根；`plugin.json` 用 `"skills": ["./.claude/skills"]`，使 `.claude/skills/assembly-development/SKILL.md` 这一份物理文件同时被项目级 skill 发现（本仓库会话直接用）与插件发现（分发安装后带命名空间）。SKILL.md frontmatter 显式 `name: assembly-development` 保证调用名稳定。
- 备选：根目录 `skills/` 布局 + 项目内软链接 —— 未选，Windows symlink/junction 脆弱。
- 后果：开发期不得在本仓库内安装本插件（防同名双加载）；用 `claude plugin validate . --strict` 与 scratch 目录 `--plugin-dir` 验证。
