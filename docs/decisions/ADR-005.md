# ADR-005：无 persona 合同驱动

- 状态：已接受（2026-08-13）
- 决策：不定义任何角色人格（无 `.claude/agents`、无 ROLE_ID、无“你是架构师”）。所有 subagent 统一 `general-purpose`，只接收任务合同：机械身份（RUN_ID/TASK_ID/PHASE/CONTRACT_ID/CONTRACT_VERSION/CONTRACT_SHA256）+ 目标/范围/步骤/验收/证据。职责隔离由阶段合同（clarify/plan/implement/integrate/verify/release）与 worktree/工具/状态隔离实现。独立验证是风险控制属性（新上下文、只读、不得改实现后自批），不是角色。
- 备选：`.claude/agents/*.md` 角色定义 —— 已弃（不可移植、占用上下文、无法机械验证、引入行为偏置）。
- 后果：质量以硬不变量 + 行为验收 + 位置化结构审查证据表达，禁止评分/行数/覆盖率总指标（防 Goodhart）。
