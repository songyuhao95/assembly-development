# ADR-001：事件优先（events-first）运行事实真源

- 状态：已接受（2026-08-13）
- 决策：`run/events.ndjson` 是运行事实唯一真源（append-only、单行 JSON、单写者、单次写一行）；`state/approvals/risks/worktrees/evidence` 全部是从事件确定性重建的投影（gitignore，可随时删除重建）；`run/tasks/<RUN_ID>.json` 是 G2 冻结计划（冻结后不改写）；UI 只消费统一 `snapshot` envelope。
- 备选：state.json 为主真源、events 仅审计 —— 未选，因为恢复/审计需要完整事实链。
- 后果：所有状态变更必须走事件追加；投影与快照不得手工编辑；恢复 = 重建投影 + reconcile 外部资源（worktree/commit/report）。
